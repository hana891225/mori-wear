# MORI 衣著

繁體中文服飾概念商店，以奶油白與森林綠為主色，支援桌面與手機瀏覽。

公開網站：https://hana891225.github.io/mori-wear/

推送至 `main` 分支後，GitHub Actions 會自動將 `dist/` 部署至 GitHub Pages。

## 功能

- 商品分類、關鍵字搜尋與價格排序
- 商品詳情、尺寸與顏色選擇
- 收藏、購物袋、數量調整與金額小計
- 透過 localStorage 保留購物袋與收藏
- 示範結帳摘要與尺寸指南

## 專案結構

- `dist/index.html`：頁面內容
- `dist/style.css`：響應式樣式
- `dist/app.js`：商品資料與購物操作

## 本機預覽

這是純 HTML、CSS 與 JavaScript 網站，不需要安裝套件或建置。可直接開啟 `dist/index.html`，或使用任意靜態 HTTP 伺服器將 `dist` 設為網站目錄。

## 修改商品

修改 `dist/app.js` 的 `products` 陣列即可調整商品名稱、價格、圖片、分類與顏色。尺寸選項目前為示範設定。

## 使用限制

商品與價格均為示範資料，尚未串接金流、物流、後端訂單、庫存及客服服務；結帳不會建立正式訂單或收取款項。

圖片使用 Unsplash 外部網址，字型使用 Google Fonts，載入這些資源需要網路。購物袋與收藏僅保留在使用者的目前瀏覽器。

## 驗證

已通過 JavaScript 語法、商品分類、搜尋、購物袋規格合併、小計、本機保存、收藏與空購物袋檢查。尚未完成瀏覽器視覺驗證。
